Import Rules

  • Required columns: Name, Registration No.
  • Expected columns: CNIC, Name, Father Name, Registration No., Gender, Degree, Session, Folder/File (With GS-Forms), Comments (Missing), Synopsis, Semi-Final Thesis, Final Thesis, Thesis Forward (COE), Status.
  • Status must be one of: {{ status_list|join(', ') }}.
  • Folder/File: Completed / Not Completed. Synopsis / Semi-Final / Final Thesis: Received / Not Received.
  • Thesis Forward (COE): a date (e.g. 10-May-2026 or 2026-05-10).
  • Every row is imported as-is — duplicate Registration Nos. or CNICs each become their own record. Only fully blank rows are skipped.
  • New students get a portal password automatically: their CNIC digits (used on first login).
